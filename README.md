# Leno Tech website (frontend only)

## Run
npm install
npm run dev

## Edit
- WhatsApp number and email: src/data/content.js
- Pricing, services, projects, steps: src/data/content.js

## Deploy (GitHub Pages)
npm run build, then publish the `dist` folder (e.g. `npx gh-pages -d dist`),
or drag `dist` into Netlify.
